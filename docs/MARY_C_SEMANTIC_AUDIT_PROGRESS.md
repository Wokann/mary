# Mary-C 语义审计进度

更新日期：2026-09-06

本表记录 Mary-C callable、常量、脚本及文本符号的当前证据状态。测试通过只证明
其实际覆盖的结构与字节不变性，不自动证明所有英文语义都已确认。无法由源码、
ROM、脚本上下文或可靠资料闭合的项目继续使用编号或 `UNKNOWN` 名称。

## 审计原则

- 物理槽位与 ROM 表顺序是主键；符号名称和条件宏不得改变实际 ID。
- 官方英文名称优先；日文文本、社区工具或攻略只能提供交叉验证，不能单独证明
  原生函数契约。
- 男孩版源码不能直接证明女孩版实现；US 结论不能未经对照直接覆盖 JP。
- 类型传播在控制流合并后无法唯一确定时必须退回原始整数。
- 禁止使用 objdump；进一步的原生分析使用源码、直接 ROM 读取或 Ghidra
  Headless。
- 原生分析证据分类保存在相邻 FoMT 工程的
  `docs/mary-native-audit/`，该目录是证据库，不是完成声明。
